# GIT PRACTICE FILES

Use these sample files to practise creating a repository, making edits, reviewing diffs, staging files, and creating commits.

Suggested exercise:

1. Initialize a temporary Git repository in a copy of this practice folder.
2. Run `git status`.
3. Stage and commit the starter files.
4. Edit `project-notes.md`, then inspect the result using `git diff`.
5. Create a branch, add a small change, commit it, and merge the branch.
6. Review the commit history.

This directory contains examples only. Follow the Week 2 README and workflow guide for the complete task.
